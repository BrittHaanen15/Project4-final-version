# A Markov-Chain Monte Carlo approach to study computational and physics phenomena in a 2-dimensional Ising model

This repository contains the code for Project 4 in the course FYS3150/FYS4150 at the University of Oslo. 
The project is developed by: Britt Haanen

In this project we studied some key principles of Markov-Chain Monte Carlo (MCMC), as well as physics phenomena surrounding phase transitions using the 2-dimensional Ising model. 
The computations are implemented in C++, while Python scripts are used for visualizing the results. 


## Repository structure

The repository is organised using the src/include convention, and the file tree is as follows: 
```text
├── Benchmarking
│   ├── Euler, after 1 step, as benchmark for RK4, compare against handwritten.png
│   ├── UnitTest_FEstep.cpp
│   ├── UnitTest_ParticleClass.cpp
│   ├── ...
├── Figures
│   ├── Error vs n, FE.pdf
│   ├── Error vs n, RK4.pdf
│   ├── ...
├── Plotting
│   ├── Plotting_100_particle.ipynb
│   └── Plotting_one_and_two_particle.ipynb
├── Project3_Outputs
│   ├── 100_particles_f0.1.csv
│   ├── 100_particles_f0.4.csv
│   ├── 100_particles_f0.7.csv
│   ├── ...
├── include
│   ├── Particle.hpp
│   ├── PenningTrap.hpp
│   └── utils.hpp
└── src
|   ├── Particle.cpp
|   ├── PenningTrap.cpp
|   └── utils.cpp
├── 100_particle_system.cpp
├── Two_particle_system.cpp
├── README.md
```

- `Benchmarking` contains unit test files for some of the functions in the Ising2D class 'src/'. It also contains the file 'Skeleton_parallellised' where we did a test implementation of parallellisation across temperatures. This file was run with and without -fopenmp to perform the timing tests (naively timed with the phone stopwatch, as output files appeared incorrect). It also contains screenshots of some of the printed outputs to verify correct initialisation and handling of the Ising lattice. Finally, the 'Random' files were used to get to know randomisation in C++.
- `Plotting/` contains the Python scripts for plotting and the figures generated there. The Jupyter notebooks are organised per experiment.
- `Outputs/` contains the output data generated by the C++ scripts. The output files are organised by experiment.
- `include/` contains header files
- `src/` contains source files 
- The .cpp files in the main folder are the ones used for generating the results



## Requirements 
The C++ code requires a compiler supporting C++20. 

The Python scripts require Python 3 and the packages pandas, NumPy, Matplotlib and SciPy.


## Building and running the code 
To build a code run the command

```
g++ -Wall FILE_TO_BUILD.cpp src/*.cpp -I include -o FILE_TO_BUILD.exe
```

To run the program, do

```
./FILE_TO_BUILD.EXE 
```

The phase transitions experiment can be compiled with OpenMP for faster results:
```
g++ -fopenmp -Wall Phase_Transitions_Search.cpp src/*.cpp -I include -o Phase_Transitions_Search.exe
```

The generated data is printed to terminal or stored in the `Outputs/` directory. 

## Plotting
Generate the figures interactively by opening the Jupyter notebooks in the `plotting/` folder and running the code cells.

The corresponding files are automatically stored in the `plotting/` directory.
